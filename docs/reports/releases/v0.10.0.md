## 核心交付

typed-decision（可选，默认关闭）：

- **Phase A**（[ADR 0010](../../adr/0010-typed-decision-capability.md)）：新增独立的能力层 crate `rss-ai-news-decision`，
  支持 TypeSafe Jev（托管）与自部署 laya-server 两个 provider；问题按板块配置（`[[category.decision.questions]]`），
  响应逐项校验（键集合、取值域、概率和、argmax、期望值、Laya 置信度复算），错误分类闭合且不回显错误体。
  config 只透传 `[decision]` / `[category.decision]`，`validate-config` 校验并给出 warning。
- **Phase B**（[ADR 0011](../../adr/0011-decision-run-shadow-runner.md)）：新增 `decision-run` 子命令（影子运行），
  对近期文章提问，只把校验后的答案写入新表 `decision_results`（另有策略快照表 `decision_policies`）。
  不写 `articles.state`、AI 结果或 `raw_artifacts`，**不在 `run` 中**，需单独调度。
  - 按窗口领取 + 板块轮转 + 单次请求预算；四类失败处理（单篇可重试 / 永久、全局与文章无关 / 疑似配置）；
    正确性不依赖计时（唯一键、owner 条件、调用预算）。
  - 原始响应留档策略 `on_failure | always | never`，只保存合法 JSON 且不含 key 的 2xx，带 TTL 清理；
    回放为库入口 `revalidate`（不扩展 `replay` 命令，已批准的不变量 7 例外）。
- 两家真机探针（各 1 次请求）通过；Jev 返回 2 位小数，精度容差 ε = 5e-3 定为正式值。

安全（依赖更新）：

- rustls 0.23.43 → 0.23.46：合并 Dependabot PR #2 时锁文件被退回到 v0.9.1 之前的版本，重新引入
  RUSTSEC-2026-0285 / -0346 / -0348 / -0349（经 reqwest / hyper-rustls / octocrab 处于实际依赖图）。本版恢复。
- webpki-root-certs 1.0.9 → 1.0.11（RUSTSEC-2026-0383，经 octocrab 0.54.4 引入）。
- 合入 PR #2（tokio 1.53.3、serde_json 1.0.154、octocrab 0.54.4）与 PR #3（TLS 信任相关 crate、aws-lc-rs / aws-lc-sys 对齐）。

## 升级与行为变更

| 变更 | 影响 |
|---|---|
| 新迁移 `0006_decision_results`（两方言） | 新增 `decision_policies` / `decision_results` 两张表；任何写命令首次运行时自动应用，也可先 `migrate run` |
| `[decision]` 新增 7 个可选字段 | 只被 `decision-run` 使用；旧配置照常加载 |
| 新子命令 `decision-run` | 默认不运行；启用需 `[decision] enabled = true`、凭据 env 与板块问题，并另配调度 |
| `validate-config` warning | 可能新增 `decision_inert` / `decision_model_alias` / `decision_unused_field` / `decision_budget_below_round_one` |
| 未配置 `[decision]` | 行为与 v0.9.1 相同 |

**回退**：本版有 schema 变化。数据库一旦应用 0006，v0.9.1 的二进制会因"已应用但源码中不存在的迁移"拒绝运行。
升级前请备份数据库；回退时需从备份恢复，或在确认不需要 decision 数据后按
[ADR 0011 §13](../../adr/0011-decision-run-shadow-runner.md) 的思路以新版本删表，而不是直接换回旧二进制。
