# Release v0.3.0

- tag：`v0.3.0`
- 日期：2026-05-22
- 范围：v0.2.0..v0.3.0

## 核心交付

质量与配置灵活性双线推进：

1. **质量门禁**：pre-commit hook（cargo fmt + clippy）+ 422 lost-update 重试加固 + freeze race 回归
2. **AI 任务 category 隔离**：`ai-run` 的 task_gen 与 claim_pending 按 `category_key` 圈定范围 ——
   多 worker 跑不同分类时不再误抢
3. **分类级 path_template 覆盖**：`[publish_override].path_template` 允许分类独立定义发布路径
   （详见 [[ADR-0008]]）
4. **若干 bug 修复**：deced7f 的两个自审 bug、pre-commit 可执行位
