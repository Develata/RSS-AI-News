## 核心交付

**RSSHub 占位符语义 + access_key 处理一次性收口**（5 个连续 commit，对应 [[ADR-0007]]）：

1. **占位符运行时展开**：feed_url 中的 `{RSSHUB}` 在 ingest 路径上展开为 `EnvConfig.rsshub_base_url`，
   末尾斜杠由 `trim_end_matches('/')` 清理
2. **access_key 分离**：把 RSSHub `access_key` 从 `feed_url` 中剥离，单独走 `SourceSecrets`
   per-source 注入 —— 持久化的 feed_url 不再含密钥
3. **`{RSSHUB_BASE_URL}` 别名**：在原 `{RSSHUB}` 之外接受新别名，兼容老配置
4. **占位符诊断对齐**：缺 `RSSHUB_BASE_URL` 时 validate 报错文案统一指向两个支持的占位符
