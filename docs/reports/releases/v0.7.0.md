1. **`recent-entries` read-only export surface**：按 category / discovered time 导出 recent feed entries，附 active-source health summary；SQLite / PostgreSQL 双方言、JSON envelope、read-only PG session 与 CLI errors 均有验收。

3. **跨源 link dedup 原子化**：关闭 v0.6.2 defer 的 P1-1 SELECT→INSERT TOCTOU race。migration 0004 保留历史 duplicate rows，以最低 id 为 canonical，其他行标 `link_dedup_shadow`；partial unique index 由数据库原子裁决新写入。
4. **dependency security hardening**：升级 feed-rs / quick-xml、Octocrab / jsonwebtoken、rustls-webpki、quinn-proto、rand、anyhow、serde_with 等；package/binary identity 从 `0.1.0` 对齐到 `0.7.0`。
5. **release contract 收口**：active docs 与历史 reports 对齐真实 GHCR 命名（同 package 的 `-scheduler` suffix）、真实 tag aliases 与五 job CI；补录 v0.5/v0.6 minor reports。

## Schema / upgrade

自动应用双方言 migration `0004_feed_entry_link_dedup_atomicity`：

- 新增 `feed_entries.link_dedup_shadow`（默认 false / 0）；
- 每组存量重复 `link_hash` 按最小 id 保留 canonical，其他行只标 shadow，**不删除** audit/state/article 关系；
- 新增 canonical `link_hash` partial unique index；
- link-hash reindex 每次 move 在事务内锁定写路径，并对 old/new hash groups 按最小 id 原子重选 canonical；candidate 非最小 id 时记 `conflict_skipped`，collision chain 不会留下 shadow-only group。

回滚会移除 index/column，并重新暴露 SELECT→INSERT race；`0004.down` 必须与旧 binary 同步切换，
禁止让仍读写 `link_dedup_shadow` 的 v0.7 binary 连接已 down-migrate 的 schema。
