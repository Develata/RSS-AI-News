## 核心交付

1. **extract fallback**：抓取期永久失败可按契约转摘要兜底；Atom `<content>` 仅在文本/HTML/XML content type 下回退到 `summary_raw`。
2. **状态机健壮性**：修复 `reset_failed_in_window` 回到死状态的问题；补 5 个状态机的崩溃恢复与停泊态回收 invariant tests。
3. **配置与 owner identity**：feed body 上限与 HTML body 上限解耦；worker owner id 改为 `{host}-{pid}-{ulid}` 全局唯一。
4. **3am observability**：doctor 增加卡住 reindex、silent source 与 pending backlog 检查；从未成功的 source 以 `created_at` 计龄。
5. **组织收口**：runtime flow 与大型 tests 按关注点拆分，并同步 map / plan。
