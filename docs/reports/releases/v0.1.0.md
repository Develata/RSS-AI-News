# Release v0.1.0

- tag：`v0.1.0`
- 日期：2026-05-22
- 范围：项目从 0 到 1（W0–W11 全部交付）打包发布

## 核心交付

v0.1.0 是项目首个稳定发布版本，捆绑了从零开始的 W0–W11 全部建造期工作：

- **主链路 5 段**全部落地：ingest → extract → ai-run → publish → publish-remote
- **12 crate workspace**结构成型（root binary + 11 lib crate）
- **存储双方言**：SQLite + PostgreSQL；StoragePool enum 分裂 + 双份迁移文件
- **4 状态机** + claim+lease 并发模型
- **AI 客户端**：OpenAI 兼容、prompt 版本化、JSON schema 校验
- **发布段**：snapshot 冻结 + 字节相等 rebuild + 本地 / GitHub 双 target
- **CLI surface**：12 个子命令 + clap derive args
- **观测栈**：tracing + Prometheus metrics + run_events + HealthCheck/doctor
- **Docker multi-stage 镜像**与 **scheduler 镜像** + supercronic 外挂调度
- **CI**：4 个并行 job（lint / test / migrate with PG service / docker-build）
- **release 自动化**：push tag `v*` → GHCR 双镜像发布
